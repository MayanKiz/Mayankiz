# Hi, I'm Mayank Yadav 👋

I'm a **full-stack developer and creative builder** who enjoys turning ideas into useful, interactive products. I work across modern web development, AI-powered experiences, real-time applications, and playful browser projects.

## About me

- I build responsive web apps with a focus on clean interfaces and practical user experiences.
- I work with JavaScript/TypeScript, React, Next.js, Node.js, and backend tools such as Express, FastAPI, Django, Supabase, and Prisma.
- I enjoy experimenting with AI products, real-time features, developer tools, and game-like experiences.
- I also explore visual design, video editing, and creative workflows to make products feel more engaging.
- I am always learning, shipping small experiments, and improving projects through hands-on development.

## What I do

**Full-stack web development** — Building frontend experiences, APIs, authentication flows, databases, and production-ready deployments.

**AI and real-time applications** — Creating chat experiences, companion apps, identity-aware products, and collaborative features.

**Interactive products and games** — Designing fast, responsive browser experiences with scoring, streaks, leaderboards, and polished UI.

**Developer tools** — Building reusable React components and utilities that make coding and content workflows simpler.
